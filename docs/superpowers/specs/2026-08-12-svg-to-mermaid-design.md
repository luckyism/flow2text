# 设计文档:SVG 流程图 → Mermaid 文本技能(svg-to-mermaid)

- 日期:2026-08-12
- 状态:已获用户批准(2026-08-12)
- 范围:仅当前项目(global-workspace)

## 1. 目标

开发一个 Reasonix 技能,将用户上传的任意来源 SVG 矢量流程图转换为 Mermaid 语法文本,使文字能完整表达流程图的逻辑(节点、判断分支、循环、泳道),并可在支持 Mermaid 的平台上再渲染回图。

## 2. 需求确认

| 项 | 决定 |
|---|---|
| 输入 | SVG(任意来源,如 draw.io / Figma / Visio / 手写) |
| 输出 | Mermaid 流程图语法 |
| 部署 | 仅当前项目(`.reasonix/skills/`) |
| 实现 | 脚本 + LLM 混合(脚本确定性提取,LLM 语义组织) |

## 3. 架构

```
用户上传 SVG → agent 定位文件
   │
   ▼
svg2struct.py(Python 3 标准库,零依赖)   ← 确定性提取
   │  解析:文本框 / 形状 / 连线 + 坐标
   │  关联:箭头端点 → 最近节点 → 边表
   ▼
JSON 中间表示 {nodes:[{id,text,type,x,y}], edges:[{from,to,label}]}
   │
   ▼
agent(LLM)基于中间表示组织成 Mermaid   ← 语义组织
   │  形状→节点符号,标签→边文字,识别分支/循环/泳道
   ▼
输出 Mermaid 文本
```

分工理由:坐标匹配、XML 提取是确定性工作,交给脚本保证不漏不错;"哪个节点是判断、循环回哪、泳道分组"是语义推断,交给 LLM。

## 4. 文件布局

```
.reasonix/skills/svg-to-mermaid/
├── SKILL.md            ← 触发描述 + 处理步骤 + 输出规范
└── scripts/
    └── svg2struct.py   ← 可独立测试;SKILL.md 中给出调用方式
```

## 5. 脚本提取逻辑(svg2struct.py)

- **文本框**:所有 `<text>` 节点,合并 `<tspan>`,记录 x/y/内容;兼容 draw.io 的 `<foreignObject>` 内嵌 `<div>` 文字
- **形状**:`<rect>`(处理框)、4 点多边形(菱形判断)、`<ellipse>`/`<circle>`(起止节点)、圆角矩形
- **连线**:`<line>` / `<polyline>` / `<path>`,识别 `marker-end` 或 draw.io `endArrow` 属性判断方向
- **关联**:每条箭头按起点/终点坐标与最近的形状中心(或文本框)匹配,生成 `from → to`
- **输出**:JSON 中间表示(节点表 + 边表 + 每条节点坐标/包围盒)

## 6. 输出 Mermaid 规范

- `flowchart TD` / `LR`(按整体布局自动选择方向;优先 TD)
- 节点符号:`A[处理]`、`B{判断?}`、`C((开始/结束))`、`D[/输入输出/]`
- 边:`A --> B`;带标签:`A -->|是| B`、`A -->|否| C`
- 泳道/分区:检测到明显纵向分组时用 `subgraph`
- 无法提取的图内位图文字:`<image>` 处输出注释标注,不猜测内容

## 7. 边界情况

| 情况 | 处理 |
|---|---|
| 无箭头 | 按几何位置推断流向(自上而下为主,自左而右为辅) |
| 箭头端点悬空 | 最近邻匹配到最近的节点 |
| 循环回路 | 正常输出回边(如 `D --> B`) |
| 嵌套 `<g>` / 图层 | 递归展开 |
| 旋转 / 竖排文字 | 保留原文,不强行重排 |
| `<image>` 位图 | 占位标注,不猜测内容 |

## 8. 验证方案

- 构造 3 个测试 SVG:
  1. draw.io 导出样例(含分支 + 循环)
  2. 手写 SVG 样例(含判断分支 + 循环回路)
  3. 含泳道样例
- 验证标准:
  - 脚本对每个样例输出 JSON 结构完整、节点/边数量正确
  - agent 生成的 Mermaid 语法可被渲染(语法正确)
  - Mermaid 表达的逻辑与原图一致(分支、循环、标签不丢失)

## 9. 成功标准

- 用户在 Reasonix 会话中上传 SVG 并触发本技能后,得到可直接渲染的 Mermaid 文本
- 文本保留:全部节点文字、连线标签、分支与循环逻辑、泳道分组
- 技能仅部署于当前项目,不污染全局
